About VNtyper Online

VNtyper Online is a free, browser-based tool for MUC1 VNTR genotyping using the VNtyper 2.0 algorithm. It enables rapid screening for mutations in the MUC1 coding variable number of tandem repeats (VNTR), the most common cause of Autosomal Dominant Tubulointerstitial Kidney Disease (ADTKD-MUC1), also known as Medullary Cystic Kidney Disease (MCKD).

How It Works

Upload your BAM/BAI sequencing files. Only the MUC1 region is extracted locally in your browser using BioWasm, ensuring genomic privacy. The extracted reads are then analyzed server-side by VNtyper 2.0 to detect the prototypic cytosine insertion (insC) mutation and other VNTR alterations.

Who Is This For?

VNtyper Online serves geneticists, nephrologists, and researchers investigating ADTKD, ADTKD-MUC1, chronic kidney disease of unknown etiology, and familial kidney disorders. It democratizes access to MUC1 genotyping by working with standard short-read sequencing data (Illumina WES/WGS).

Research & Clinical Disclaimer

Research Use Only

Important Notice: vntyper-online is designed for academic and educational research purposes only. It is not an in vitro diagnostic (IVD) medical device and must not be used as the sole basis for clinical decision-making.

Diagnostic & Clinical Guidance

Evaluation of suspected Autosomal Dominant Tubulointerstitial Kidney Disease (ADTKD) should be performed in consultation with qualified clinical geneticists and nephrologists. Variant calls should be interpreted alongside clinical phenotyping and confirmed per accredited laboratory standards.

Data Protection & Privacy

Genomic alignments are sliced client-side within your browser via WebAssembly (samtools). Only extracted regional MUC1 reads are transmitted over encrypted TLS. Temporary read files are deleted immediately upon completion, and result files are automatically purged after 3 days.

Frequently Asked Questions

Guidance on data privacy, file preparation, reference builds, and diagnostic workflows.

vntyper-online provides web-based MUC1 VNTR mutation detection powered by the VNtyper 2 algorithm. Target region read extraction executes directly inside your browser via WebAssembly (samtools), meaning only a small subset of relevant reads is sent to the server for variant calling. Your raw genomic sequencing files never leave your computer.

You can upload BAM, BAI, CRAM, CRAI, or SAM files using the file input section on the home page:

  • BAM / CRAM Files: Ensure each alignment file has an accompanying index (e.g., sample.bam and sample.bam.bai or sample.bai). The index allows fast browser-side regional slicing without reading the entire multi-gigabyte file.
  • IGV SAM Export: Open your alignment in IGV, type muc1 in the search bar, right-click the alignment track, and select Export Alignments. Save the resulting SAM file and upload it directly.

vntyper-online follows rigorous data minimization and transport security best practices (Mozilla Observatory A+, SSL Labs A+, ImmuniWeb A+):

  • Client-Side Slicing: Raw genomic data stays on your machine; only targeted reads are sent to the backend.
  • Ephemeral Computation: Uploaded read data is immediately purged upon completion of the genotyping run.
  • 3-Day Result Retention: Result files are retained for 3 days to allow user retrieval, after which they are permanently deleted.
Access Security Notice: Your results URL acts as a bearer token. Anyone with the link can view and download the result files. Treat the link securely and do not share or post it publicly.

vntyper-online supports both major human reference genomes: GRCh38 / hg38 (chr1:155,185,824-155,192,915) and GRCh37 / hg19 (chr1:155,158,000-155,163,000). The assembly can be selected manually or auto-detected from BAM/CRAM header metadata.

After job submission, progress is displayed live in the output section via polling. Once analysis completes, you can review variant metrics directly on screen or export the results as JSON and TSV packages.

See our dedicated ADTKD-MUC1 Diagnostics & Guidelines reference page for the European ADTKD-Net consensus recommendations, decision tree, interpretation tier criteria (High Precision, Uncertain, Negative), and accredited international referral laboratories.
